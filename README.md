## 📖 نظرة عامة

حاسبة بسيطة وسريعة تتيح لك تحويل العملات الثلاث (الدولار الأمريكي، الدينار العراقي، التومان الإيراني) بشكل لحظي. 

المشكلة الأساسية التي تحلّها: **أسعار الصرف في السوق العراقية والإيرانية تتغير يومياً**، ولا توجد حاسبة مرنة تسمح بإدخال السعر يدوياً والتحويل بين العملتين مباشرة بدون المرور بالدولار.

هذه الحاسبة تحل ذلك ببساطة: تدخل سعر اليوم، وتحصل على التحويل الفوري.

## ✨ المميزات

- 🔄 **تحويل ثلاثي فوري** — اكتب في أي خانة، والباقي يتحدّث تلقائياً
- ✏️ **أسعار قابلة للتعديل** — حدّث السعر يومياً حسب السوق
- 💾 **حفظ تلقائي** — الأسعار تُحفظ في المتصفح (localStorage)
- 📴 **يعمل بدون إنترنت** — بعد التثبيت، لا يحتاج اتصالاً
- 📱 **قابل للتثبيت** — ثبّته على جوالك كأيقونة تطبيق
- 🌐 **دعم كامل للعربية** — واجهة RTL وأرقام عربية وهندية
- 🎨 **تصميم عصري** — واجهة داكنة أنيقة ومتجاوبة
- ⚡ **بدون مكتبات** — HTML/CSS/JS خام فقط، حجم صغير جداً
- 🔒 **خصوصية كاملة** — لا سيرفرات، لا تتبّع، كل شيء محلي
