# iqd-toman
 حاسبة ويب (PWA) للتحويل الفوري بين الدولار الأمريكي والدينار العراقي والتومان الإيراني، بأسعار صرف يومية قابلة للتعديل، تعمل بدون إنترنت وقابلة للتثبيت على الجوال.:  A Progressive Web App (PWA) for instant currency conversion between USD, Iraqi Dinar (IQD), and Iranian Toman (IRT) with editable daily rates. Works offline and installable on mobile.
